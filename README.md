# PitchBlack Recovery Project (PBRP) for Redmi Note 8 Pro (`begonia`)

Automated **GitHub Actions** CI builder and complete device tree for **PitchBlack Recovery Project (PBRP 12.1)** on **Xiaomi Redmi Note 8 Pro** (`begonia` / `begoniain`).

## Features
- **Pure AMOLED Black UI**: Minimal power draw and modern dark theme.
- **Treble & FED Tools**: Built-in Treble compatibility bypass and forced encryption disabler.
- **Unified Partition Support**: Mounts both legacy physical partitions and retrofitted dynamic partitions (`super`).

## Build via GitHub Actions
```bash
gh workflow run "PBRP Recovery Build (begonia)"
```
Or trigger manually from the **Actions** tab on GitHub.
